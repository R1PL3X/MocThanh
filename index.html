Kết Nối Database Supabase Cho Mộc Thịnh

💡 Để ai trên internet cũng xem được:
1. Tạo Project miễn phí tại supabase.com
2. Mở mục SQL Editor và chạy toàn bộ mã trong file supabase-schema.sql (đã tạo sẵn trong thư mục dự án).
3. Lấy Project URL và Anon Key dán vào bên dưới rồi nhấn "Kiểm tra kết nối".
Đây là Public Anon Key an toàn dùng trực tiếp ở phía trình duyệt người xem.
